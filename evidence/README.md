# Evidence

Артефакты для отчёта: скриншоты прогонов GitHub Actions и JSON/HTML-отчёты сканеров.

| Папка | Содержание |
|-------|------------|
| `01-cicd/` | CI/CD, GHCR, локальный стенд, VPS |
| `02-sast/` | Semgrep |
| `03-dast/` | OWASP ZAP |
| `04-security-checks/` | Gitleaks, Trivy, npm audit |
| `05-security-gateway/` | Security Gateway, PR |

Отчёты также доступны в Artifacts соответствующих workflow на GitHub.
